Research

LLM Comparative Framework for Automated Technical Question Generation

BSc thesis · Supervisor: Dr. Tamás László Storcz · 2025 – expected Feb 2027

code

A reproducible pipeline that generates technical multiple-choice questions with six LLMs from five providers: GPT-4o, GPT-OSS 120B and Llama 3.3 70B (via NVIDIA NIM), Mistral Large & Small, and Cohere Command A. It scores every question with three deterministic measures, so the same question always gets the same score:

  • I · Semantic alignment cosine similarity between source text and question
  • II · Linguistic complexity Flesch–Kincaid grade level
  • III · Distractor plausibility Jaccard similarity between correct and wrong options

Every run, prompt, question, score and token cost is versioned in a relational store (SQLAlchemy, SQLite in WAL mode). Batch runs execute in parallel with jittered backoff, and an expert-validation study checks the automatic scores against human judgement.

EduGen: blind human evaluation of LLM-generated exam questions

Programming 5 project, built on the thesis · Oct – Nov 2026

code

Automatic metrics alone can't prove that a question is correct or useful. EduGen puts the thesis framework in front of people: experts rate questions blind and students take an anonymous practice quiz. The platform never reveals which model wrote a question. Four services (Lab, Generator, Evaluator, Review) communicate through RabbitMQ, each with its own PostgreSQL database, and the whole system starts with one docker compose up. It has 146 automated tests, including cross-service contract tests.

About me

I grew up in Jalilpur, a village in Jhenaidah, Bangladesh. I first heard the word programming in class 8.

I learned basic C and C++ through a programme for the National High School Programming Contest (NHSPC), and compiling my first “Hello, World” is still one of my favourite memories. Exams and life pulled me away from it for a while, but I knew where I wanted to go back to.

In 2023 I was awarded both a Chinese Government Scholarship and Hungary’s Stipendium Hungaricum. I moved to Pécs to study Computer Science Engineering in English. Since then my work has moved from web programming to backend systems and, most of all, to large language models: how to use them, and how to measure them honestly.

Outside the lab I plant trees with the Evergreen Society, train in Shotokan karate, and look for any excuse to be near forests and mountains. Nature taught me patience and responsibility, and I bring both to engineering. Next, I want a master’s where I can turn this into research: evaluation methods that make AI in education fair, affordable and checkable.
